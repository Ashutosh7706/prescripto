**Prescripto** is an end-to-end, full-stack healthcare platform designed to streamline doctor appointments, patient management, and medical workflows. Built with a modern aesthetic and scalable architecture, it connects patients with specialized healthcare professionals seamlessly.

---

## ✨ Key Features

### 👤 Patient Portal
* **Doctor Discovery:** Filter specialists by field (General Physician, Gynecologist, Dermatologist, Pediatrician, Neurologist, Gastroenterologist).
* **Smart Booking Engine:** Real-time availability slots with interactive date and time selection.
* **Appointment Management:** Track upcoming schedules, view past history, and handle instant cancellations.
* **Integrated Payments:** Secure checkout support for online consultations and appointment bookings via Stripe/Razorpay integration.
* **User Profiles:** Secure profile setup, medical history storage, and personal data management.

### 👨‍⚕️ Doctor Dashboard
* **Schedule Control:** Manage dynamic availability, slot timings, and consultation fees.
* **Appointment Metrics:** Real-time overview of daily, weekly, and monthly patient bookings.
* **Earnings Analytics:** Comprehensive tracking of financial transactions and completed sessions.

### 🛡️ Admin Control Panel
* **Platform Management:** Onboard new doctors, verify credentials, and manage specialty categories.
* **Global Overview:** Monitor platform activity, total revenue, user engagement, and system analytics.
